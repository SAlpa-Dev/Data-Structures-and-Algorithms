# Data Structures & Algorithms

My personal collection of Data Structures and Algorithms solutions, solved on
[LeetCode](https://leetcode.com/u/Sujeet_sk/) and
[GeeksforGeeks](https://www.geeksforgeeks.org/profile/sujeetsk) and organised
here by platform. The focus is on writing clean, correct solutions and
understanding the time and space complexity behind each one.

## Repository structure

```
LeetCode/         solutions to LeetCode problems
GeeksforGeeks/    solutions to GeeksforGeeks problems
```

## What this covers

- **250+ problems** solved across both platforms and counting.
- A range of core topics — arrays, strings, hashing, two pointers, sliding
  window, recursion, searching and sorting, linked lists, stacks and queues,
  trees, and dynamic programming.
- An emphasis on analysing the **time and space complexity** of each approach,
  not just passing the test cases.

## Purpose

This repository is a running log of my problem-solving practice. I use it to
track progress, revisit patterns, and keep my fundamentals sharp while
preparing for technical interviews.

## Languages

Solutions are written primarily in **Java**.
